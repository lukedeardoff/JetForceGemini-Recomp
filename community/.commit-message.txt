Faces in floor reflections; hide the stretched column; crash report file

- Floor reflections: DMA triangles are now culled like JFG's own RSP
  microcode. While the game draws mirrored objects it sets G_CULL_FRONT,
  which turns the microcode's per-triangle back-face cull into a front-face
  cull; double-sided triangles (flag 0x40) are never culled. The old
  GLideN64 rule ignored that bit, so faces (Tribals, Vela) were missing
  from the floor reflections on the ship level.
- JFG_HIDE_TEXTURES: DMA-triangle draws whose first texture tile has a
  listed RT64 hash (as the inspector shows it) are skipped. The default
  hides the stretched blue column on the ship level (004af4b8010a38d8),
  which the N64 also draws but much less visibly; "none" turns it off.
- Crash report: a crash also writes
  %LOCALAPPDATA%\JFGRecomp\diag\crash-report.txt (last guest instruction,
  the guest address behind an access violation, registers of the running
  guest thread, last guest calls, host stack) and crash-rdram.bin (guest
  RAM). Local diagnostics only.
- play-community.ps1 lists JFG_* test settings still set in the same
  PowerShell window from an earlier run.
- community/README.md updated.
